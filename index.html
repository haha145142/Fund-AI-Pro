📋 数据口径说明 · 反推估值原理 · 部署教程 一、盘中估值方法（养基宝/小倍养基同款·重仓股穿透）
官方实时估值 2026 年下架后，采用三条独立路线反推基金盘中涨跌：
① 重仓股穿透——前十大重仓股占净值比例加权 × 个股实时涨跌（个股价格取腾讯 qt.gtimg.cn + 东财 push2delay 双源）
② 行业指数拟合——重仓股按东财行业归类 × 行业板块指数涨跌
③ 主题指数拟合——基金主题映射到代表板块指数涨跌
联接/指数型基金以其目标 ETF 或跟踪指数涨跌为准。

二、交叉验证
• 个股/ETF 价格：腾讯 + 东财 双源比对，差异 < 0.3% 采信
• 板块涨跌：东财「clist 资金流排行」与「stock/get 行情」双端点
• 指数：腾讯 + 东财 双源

三、分歧判定（0.8% 红线）
三路估值 max−min > 0.8% 时标红「可能已调仓」（重仓股已偏离最新季报）。

四、收盘切换
交易时段（9:30-11:30 / 13:00-15:00）：显示盘中三路反推估值，30 秒自动刷新
收盘后（15:00 后 / 非交易日）：自动切换为官方净值（天天基金 pingzhongdata），不再估算

五、板块关联基金来源
板块关联基金列表参考原页面（zoujie520.pages.dev）+ 天天基金/东财公募排行，覆盖各板块主流指数基金与主动基金，每板块代表性 3 只。

六、Cloudflare Pages 部署（5分钟上线·免费）
把这个 index.html 单文件拖到 dash.cloudflare.com → Workers & Pages → Pages → Create application → Upload assets → 拖入文件 → Deploy site。
约 30 秒后获得 https://xxx.pages.dev 链接，手机电脑直接打开就实时跑数据。
全程免费、无需绑卡、国内可访问。GitHub 集成方式见 Cloudflare Pages 文档。

七、季度更新
持仓数据来自基金每季度季报（约 4/7/10/1 月公布）。季报更新后重抓持仓、重新生成 index.html、重新部署即可。

八、改成自己的持仓
打开 index.html 找到顶部 FUNDS 与 SECTOR_FUNDS 数组：
• 主动基金填 type:"active" + stocks:[{code,name,w},…]（前十大重仓股，在 fundf10.eastmoney.com 查）
• 指数联接填 type:"index" + theme:{code:"BKxxxx",name:"板块名"}
保存 → 重新上传部署即可。
